# Mendocino Physical Therapy: Life, In Motion

Independent local concept, not the practice's live website. Open `index.html` in a browser, or serve this folder on localhost. No dependencies, build step, tracking, storage, forms or network scripts. Goal buttons change illustrative artwork and explanatory content locally.

Read `docs/CONCEPT.md` for the creative direction, `docs/RESEARCH.md` for the comparison sample, and `docs/EVIDENCE.md` for acceptance limits. Research is a bounded seven-site review including Mendocino, not an exhaustive internet census.

Before release: run `python scripts/apply_colophon.py --check`, `python scripts/check_release_links.py`, the web workflow/profile and project-mapping validators, and responsive/keyboard review. Publication is not authorized by this scaffold request.
